# Phase 1 Design Documents

This directory contains the storyboards and wireframes created before implementation of the application.

The designs describe the proposed user interface, navigation and permission-based functionality for regular users, group administrators and the super administrator.

## Storyboards

- Login
- Registration
- Groups
- Group Rooms
- Chat Room
- Profile
- Group Administrator Dashboard
- Super Administrator Dashboard

These designs will guide the Angular frontend implementation during Phase 1.
